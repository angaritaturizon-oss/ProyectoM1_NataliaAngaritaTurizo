# Generador de Paletas de Colores - Proyecto Integrador - ProyectoM1_NataliaAngaritaTurizo

Una página web que permite generar paletas de colores de forma aleatoria y visualizar sus valores en diferentes 3 formatos y tamaños.

## ✨ Características

* Generación de paletas de colores aleatorias.
* Selección de cantidad de colores:

  * 6 colores
  * 8 colores
  * 9 colores
* Selección del formato del color:

  * HEX
  * RGB
  * HSL
* Visualización del valor de cada color.
* Opción para copiar la paleta generada.

## 🛠️ Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript

## 📁 Estructura del proyecto

```text
GeneradorDePaletas/
│
├── index.html
├── colores.css
└── colores.js
```

##  Uso

1. Selecciona la cantidad de colores que quieres generar.
2. Selecciona el formato del color.
3. Haz clic en **Generar Paleta**.
4. Visualiza los colores y sus respectivos valores.
5. Utiliza **Copiar Paleta** para copiar los colores.
